# Ubuntu Animal Rescue Website

## Project Overview
A comprehensive website for Ubuntu Animal Rescue, a non-profit organization dedicated to rescuing, caring for, and rehoming animals across South Africa. This website serves as a digital platform to facilitate animal adoptions, donations, volunteer recruitment, and community engagement.

## Website Structure
- **Home** (`index.html`) - Landing page with mission overview and key features
- **About** (`about.html`) - Organization history, team, and achievements
- **Adoption** (`adoption.html`) - Available pets and adoption process
- **Events** (`events.html`) - Upcoming fundraisers and community events
- **Donations** (`donations.html`) - Support options and donation processing
- **Contact** (`contact.html`) - Contact forms and location information

## Technical Stack
- **Frontend**: HTML5, CSS3, JavaScript 
- **Libraries**: jQuery, Leaflet.js (Maps)
- **Styling**: Custom CSS with responsive design
- **Icons**: Font Awesome (via CDN)
- **Maps**: OpenStreetMap with Leaflet
